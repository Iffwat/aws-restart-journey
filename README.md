## Documentation principles
1. Record what was actually performed and observed.
2. Separate lab-specific instructions from additional explanations.
3. Never commit AWS access keys, passwords, private keys, session tokens, or credentials.
4. Sanitize screenshots by removing account IDs, IP addresses where sensitive, and personal information.
5. Do not publish proprietary course materials unless permitted.
